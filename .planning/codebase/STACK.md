## Configuration

**Environment:**
- Configuration driven by environment variables
- Support for `.env`, `.env.local`, `.env.production` files
- Vercel deployment detection via `VERCEL` and `VERCEL_PROJECT_PRODUCTION_URL`

**Key Configuration Variables:**
- `DATABASE_URL` - PostgreSQL connection string
- `PAYLOAD_SECRET` - Secret key for Payload
- `NEXT_PUBLIC_SERVER_URL` - Frontend server URL
- `NEXT_PUBLIC_SITE_NAME` - Site name (defaults to 'SNS')
- `PREVIEW_SECRET` - Draft preview authentication
- `CLOUDINARY_CLOUD_NAME` - Cloudinary cloud identifier
- `CLOUDINARY_API_KEY` - Cloudinary API key
- `CLOUDINARY_API_SECRET` - Cloudinary API secret
- `SMTP_HOST` - Email server hostname
- `SMTP_PORT` - Email server port (defaults to 587)
- `SMTP_USER` - Email authentication username
- `SMTP_PASS` - Email authentication password
- `SMTP_FROM` - Default from address
- `SMTP_FROM_NAME` - Default from name
- `NEXT_PUBLIC_SITE_NAME` - Site display name

**Build:**
- `next.config.ts` - Next.js configuration with Payload integration
- `tsconfig.json` - TypeScript compiler options
  - Strict mode enabled
  - Path aliases: `@/*` → `src/*`, `@payload-config` → `src/payload.config.ts`
  - Target: ES2022
- `vitest.config.mts` - Integration test configuration
- `playwright.config.ts` - E2E test configuration

## Platform Requirements

**Development:**
- Node.js 18.20.2+ or 20.9.0+
