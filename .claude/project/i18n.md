# Internationalization (i18n)

## Single source of truth

`src/i18n/languages.ts` is the **only** file to edit when adding or removing a language.
Everything else — Payload localization config, SiteSettings select options, locale validation
in middleware — derives from this array automatically.

```ts
// src/i18n/languages.ts
export const LANGUAGES: Language[] = [
  { code: 'en', label: 'English' },
  { code: 'mr', label: 'Marathi' },
]
export const DEFAULT_LANGUAGE_CODE = 'en'
```

To add Hindi: append `{ code: 'hi', label: 'Hindi' }` — nothing else changes.

## Payload localization config

`src/payload.config.ts` maps `LANGUAGES` into Payload's `localization` option:

```ts
localization: {
  locales: LANGUAGES.map(({ code, label }) => ({ code, label })),
  defaultLocale: DEFAULT_LANGUAGE_CODE,
  fallback: true,   // missing locale falls back to defaultLocale
}
```

## Marking a field as translatable

Add `localized: true` to any Payload field. Payload adds a column per locale in the DB.

```ts
{ name: 'title', type: 'text', localized: true }
// → stores title_en, title_mr columns
```

Fields currently marked `localized: true`:
- Pages: `title`, hero `richText`, block `richText` fields, link `label`, SEO `meta.title` / `meta.description`
- SiteSettings: none (the `defaultLanguage` select is not localized — it's a single admin setting)

## Admin default language

`src/globals/SiteSettings.ts` — a Payload Global with a `defaultLanguage` select field.
Options are built from `LANGUAGES` so the dropdown always matches the supported locales.
Defaults to `DEFAULT_LANGUAGE_CODE` (`'en'`) if the admin has never saved.

The utility `src/i18n/getDefaultLocale.ts` reads this global; it is used by the root `/` page
to redirect visitors to the correct locale.

## Devanagari font

`globals.css` includes:

```css
:lang(hi), :lang(mr) {
  font-family: var(--font-devanagari), ui-sans-serif, system-ui, sans-serif;
}
```

Wire up a Next.js `localFont` or Google Font for Devanagari and expose it as
`--font-devanagari` via `@theme` in `globals.css`.
